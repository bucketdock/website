# website

Website for BucketDock - the open-source macOS client for S3-compatible cloud storage.

https://github.com/bucketdock/bucketdock

## Local Development

This repository contains the static website for BucketDock.

To preview it locally, run:

```bash
npx serve
```

Then open the local URL shown in your terminal.

Example:

```text

http://localhost:3000

```

The port may be different if `3000` is already in use.
